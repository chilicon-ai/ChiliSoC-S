# Security

Please report a security issue privately, not in a public issue: through
GitHub's [private vulnerability reporting](../../security/advisories/new) for
this repository, or by e-mail to security@chilicon.ai. Include the affected
file or unit, how to reproduce it (a program for `sim/run.py` or a testbench
is ideal) and its effect. We acknowledge reports within a few working days and
credit reporters who wish it.
